# 🕷 WhatsApp Story & Lead Spider (Pure Baileys)

Автономный, легковесный микросервис на чистом `@whiskeysockets/baileys` без тяжелых прослоек.

## 🎯 Что делает сервис:
1. **Отслеживание просмотров историй (Stories/Status):**
   * Перехватывает событие `message-receipt.update` на системный broadcast `status@broadcast`.
   * Мгновенно шлет в Telegram уведомление: кто посмотрел (номер), время и ID сторис.
   * Логирует всех зрителей в файл `story_views.jsonl`.
2. **Групповой Паук Лидов (Group Lead Spider):**
   * Мониторит входящие сообщения из всех ваших групп и чатов.
   * Фильтрует сигналы спроса по ключевым словам: *«ищу», «куплю», «посоветуйте», «сколько стоит»* и т.д.
   * При обнаружении лида присылает готовое уведомление в Telegram с прямым контактом автора.
3. **Автономность 24/7:**
   * Автоматический реконнект при обрывах связи.
   * Сохранение сессии в `auth_info_baileys/`.

## 🚀 Быстрый запуск

### 1. Установка зависимостей
```bash
npm install
```

### 2. Настройка окружения
Скопируйте `.env.example` в `.env`:
```bash
cp .env.example .env
```
Заполните ваши `TG_BOT_TOKEN` и `TG_CHAT_ID`.

### 3. Запуск
```bash
npm start
```
При первом запуске в консоли появится QR-код. Отсканируйте его в приложении WhatsApp (**Связанные устройства**).

## 🖥 Фоновый запуск на VPS через PM2
```bash
npm install -g pm2
pm2 start index.js --name "wa-spider"
pm2 save
pm2 startup
```
